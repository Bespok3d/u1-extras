# Attributions - klipper-hooks

**Plugin author:** Bespok3d, rewritten from the Extended Firmware overlay `35-feature-klipper-hooks` (paxx12); diverged since

Lets plugins hook into print start, end and cancel.

No third-party code ships in this package.

The idea comes from the Extended Firmware overlay `35-feature-klipper-hooks` (paxx12), GPL-3.0. That
overlay patches Klipper's source; this plugin instead overrides the macros with `rename_existing`,
written from scratch. No code from the overlay ships here.

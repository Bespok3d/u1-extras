# Changelog

## 0.1.1 (2026-08-16)

WLED Status Lights is now a stable plugin. Before, it only showed up in the store if you had set your
plugin channel to testing; now it shows for everyone. Nothing about the plugin itself changed.

## 0.1.0

- First release. Configures Moonraker's built-in `[wled]` for a network-attached WLED strip
  (address, LED count) so the printer can drive status lighting.

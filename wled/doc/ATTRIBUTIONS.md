# Attributions - wled

**Plugin author:** Bespok3d, driving Moonraker's built-in `[wled]` against WLED by Christian Schwinne (Aircoookie); WLED on the U1 was first done in the Extended Firmware overlay `12-patch-moonraker` (paxx12)

Controls WLED light strips from the printer.

| Upstream project | Author | Licence | Needed at runtime | Code ships in this package |
| --- | --- | --- | --- | --- |
| WLED | Christian Schwinne (Aircoookie) and the WLED contributors | MIT | yes | no |

WLED runs on your own light controller; nothing from it ships inside this plugin, which only
configures Moonraker's built-in `[wled]` component. Upstream: https://github.com/Aircoookie/WLED

Ported from the Extended Firmware overlay `12-patch-moonraker` (paxx12), GPL-3.0.
